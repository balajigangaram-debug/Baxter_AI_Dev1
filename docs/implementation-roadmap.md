# Implementation roadmap

1. **Groundwork:** source PDF review, ownership, data classification, platform access, security and governance approval.
2. **Foundation:** CMDB metadata contracts, ontology, Neo4j schema, adapter security, observability.
3. **Assist pilots:** ticket triage and analytics with human acceptance/override; measure baseline accuracy.
4. **Expand:** correlation, MIM drafting, debt profiling, SLA recommendations, knowledge validation.
5. **Controlled autonomy:** only after evaluation thresholds, operational readiness, and written governance approval.

The ordering above is an implementation suggestion based on the prompt; validate it against Baxter/TCS commitments.
